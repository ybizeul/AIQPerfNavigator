Base URL: api.activeiq.netapp.com/

GET `/v1/performance-data/graphs`

## Parameters

### authorizationToken

Access token to use the 'API Services'.

### graphName

Specifies the graph name that is the counter name for a graph.

**Valid values for Node based graphs:**

- node_protocol_iops
- node_network_throughput
- node_avg_iops
- node_latency
- node_headroom_cpu_utilization
- aggr_throughput
- node_headroom_aggr_utilization

**Valid values for Cluster based graphs**

- cluster_avg_iops
- cluster_network_throughput
- volume_latency
- volume_iops

### cluster

Specifies the cluster identifier for graph.

### serialNumber

Specifies the serial number of the node.

### systemId

Specifies the system ID of a node.

### startDate *

Specifies the start date for counter data for a specified duration. The valid date should be represented in the YYYY-MM-DD format, for example, 2020-01-19.

### endDate *

Specifies the end date for a counter data for a specified duration. The valid date should be later than the start date. It should be represented in the YYYY-MM-DD format, for example, 2020-05-15.

### aggregateUuid

Specifies the universally unique identifier (UUID) for an aggregate. This parameter is mandatory for either "aggr_throughput" or "node_headroom_aggr_utilization" graph.

### volInstanceUuid

Specifies the universally unique identifier (UUID) for the volume. This parameter is mandatory for either "volume_latency" or "volume_iops" graph.
